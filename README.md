# Sales Performance Analysis Dashboard – Power BI

## 📊 Project Overview

This project focuses on analyzing sales performance using Microsoft Power BI. The dashboard provides insights into sales, profit, quantity sold, product performance, customer behavior, and promotional activities through interactive visualizations.

The objective is to transform business data into meaningful insights that can help organizations monitor performance, identify trends, and make data-driven decisions.

## 🎯 Problem Statement

Businesses need to understand how their products, customers, and promotional campaigns contribute to overall sales and profitability.

This dashboard helps analyze:
- Overall net sales and profit performance.
- Product-wise sales and profitability.
- Customer distribution across different cities.
- Performance of promotional campaigns.
- Changes in sales, profit, and quantity over time.
- Relationships between sales and profitability.
